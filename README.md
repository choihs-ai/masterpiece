# PULSAR · 펄서

**음악이 곧 탄막이 되는 리듬 슈팅 로그라이트.**
모든 적은 음악의 박자에 맞춰 공격하고, 내 총성과 폭발음은 지금 흐르는 곡의 화음으로 울립니다.
음악, 그래픽, 효과음 모두 외부 파일 없이 코드로 실시간 생성됩니다.

- 바로 플레이: GitHub Pages 배포 후 `https://choihs-ai.github.io/masterpiece/`
- 아이폰·아이패드: 링크를 사파리로 연 뒤 **공유 → 홈 화면에 추가** 하면 앱처럼 전체 화면으로 실행됩니다.

> 모든 별은 저마다의 노래를 부른다. 그러나 정적이 깨어나 별들의 노래를 삼키기 시작했다.
> 마지막 선율을 실은 함선이여, 다섯 성역을 지나 펄서를 다시 점화하라.

## 무엇이 특별한가

- **박자에 맞춰 설계된 탄막**: 적의 부채꼴 탄은 정박에, 나선 탄은 8분음표에, 탄막의 벽은 마디 첫 박에 쏟아집니다. 리듬을 느끼면 패턴이 보입니다.
- **실시간 작곡 엔진**: 섹터마다 장르(신스웨이브 · 딥하우스 · 트랜스 · 브레이크비트 · 에픽)와 조성이 다른 곡이 매 판 새로 작곡됩니다. 코드 진행, 보이스 리딩, 모티프 기반 멜로디, 드럼 필인, 사이드체인까지 모두 Web Audio로 합성합니다.
- **연주가 되는 전투**: 주포는 16분음표 그리드에 맞춰 발사되고, 적이 터지는 소리는 현재 코드의 구성음으로 양자화되어 곡에 녹아듭니다. 음표를 연속으로 주우면 아르페지오가 올라갑니다.
- **PERFECT 펄스**: 공명 게이지로 충전한 펄스를 정확히 박자에 맞춰 터뜨리면 범위와 피해가 커집니다.
- **로그라이트 성장**: 24종의 업그레이드(멀티 배럴, 유도 미사일, 위성 드론, 연쇄 번개, 레조넌스 빔, 메아리탄 …)를 조합해 매번 다른 빌드를 만듭니다.
- **5개 섹터 · 5명의 보스**: 오로라 전령, 조수 소환사, 프리즘 집정관, 태양 폭군, 그리고 마지막 보스 정적. 보스는 여러 단계로 변신하며, 마지막 단계에서는 곡도 클라이맥스로 치닫습니다.
- **네온 그래픽**: Three.js 기반 3D 와이어프레임 모델, GPU 파티클, 블룸, 충격파 왜곡, 색수차, 섹터마다 다른 하늘(오로라 · 수중 빛무늬 · 성당의 빛줄기 · 적색 거성 · 블랙홀).
- **함선 3종 · 난이도 3단계 · 데일리 챌린지**(모두가 같은 시드로 경쟁) · 기록 저장.

## 조작법

| 기기 | 이동 | 펄스 | 정밀 이동 | 일시정지 |
|---|---|---|---|---|
| 터치 | 화면 아무 곳이나 드래그 (손가락에 가려지지 않는 상대 이동) | 두 번째 손가락 탭 또는 PULSE 버튼 | — | 우측 상단 버튼 |
| 키보드 | 방향키 / WASD | Space · X · K | Shift · Z | Esc · P |
| 게임패드 | 왼쪽 스틱 / 방향 패드 | A | RB | Start |

사격은 자동입니다. 피격 판정은 함선 중앙의 빛나는 점 하나뿐입니다.

## 규칙

- **그레이즈**: 탄을 아슬아슬하게 스치면 점수와 공명 게이지를 얻습니다.
- **공명 → 펄스**: 게이지가 차면 펄스가 1회 충전됩니다. 펄스는 주변 탄막을 음표로 바꾸고 적에게 피해를 줍니다.
- **체인 배율**: 연속 격파로 배율이 최대 ×8까지 오르고, 피격되면 떨어집니다.
- **진행**: 섹터마다 웨이브 2개 → 보스. 웨이브를 넘길 때마다 업그레이드 1개, 보스를 쓰러뜨리면 희귀 업그레이드 보상.
- **해금**: 섹터 1 클리어 → AEGIS(방어형), 섹터 3 클리어 → VOLT(공격형).

## 기술 구성

- TypeScript · Vite · Three.js(번들) · Web Audio API · Vitest
- 외부 에셋 0개: 사운드·텍스처·모델·아이콘 모두 코드로 생성
- 게임 로직은 렌더링·오디오와 완전히 분리되어 있어 브라우저 없이 전체 게임을 시뮬레이션하는 테스트가 돌아갑니다(봇이 5개 섹터를 끝까지 클리어하는지 검증).
- 오디오 시계 기반 스케줄러: 음은 0.16초 앞서 정확한 시각에 예약하고, 게임 이벤트는 실제로 소리가 들리는 순간에 처리해 화면과 소리가 정확히 맞습니다.
- 모바일 대응: 상대 터치 이동, 노치/홈 바 안전 영역, iOS 무음 스위치 우회(audioSession), 자동 그래픽 품질 조절, PWA 오프라인 캐시.

```
src/
  core/    난수, 수학, 저장, 한/영 문자열, 박자 이벤트 타입
  audio/   음악 이론, 작곡기(composer), 합성 엔진(engine), 박자 시계(conductor), 음악 재생, 효과음
  game/    월드(시뮬레이션), 플레이어, 탄 풀, 적, 보스, 탄막 패턴, 무기, 업그레이드, 웨이브, 진행(director)
  render/  Three.js 렌더러, 배경, 인스턴싱 배치, GPU 파티클, 네온 모델, 후처리
  input/   터치·키보드·게임패드
  ui/      메뉴·HUD·배너 (DOM), 스타일, 아이콘
tests/     단위 테스트 + 전체 게임 헤드리스 시뮬레이션
scripts/   단일 파일 빌드, 아이콘 생성, 브라우저 스크린샷 점검
```

## 개발

```bash
npm install
npm run dev          # 개발 서버
npm test             # 단위 테스트 + 전체 런 시뮬레이션
npm run build        # dist/ (GitHub Pages용, PWA 포함)
npm run build:single # dist-single/index.html (모든 것이 들어간 단일 HTML 파일)
```

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 설정합니다.
2. `main` 브랜치에 푸시(또는 PR 병합)하면 `.github/workflows/deploy.yml` 이 테스트 → 빌드 → 배포를 자동으로 실행합니다.
3. 배포 주소: `https://choihs-ai.github.io/masterpiece/`
